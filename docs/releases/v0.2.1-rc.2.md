本预发布版本汇总了自 `v0.2.1-rc.1` 以来在 Android 原生外壳、通知联动与手机端控制台体验方面的更新。

### 新增功能

- **Android 原生系统通知联动 `dsh-x-desktop-notify`**：新增后台通知同步服务（`NoticeSyncService`）与 `/_dshx/api/notices` 接口，支持「等你确认（高优先级）」与「任务完成与提醒」分通道推送；点击通知可直达对应 DSH 实例，设置页提供后台通知开关与「测试」按钮。
- **原生 WebView 内置顶部控制条与多实例抽屉切换器**：`DshWebViewActivity` 顶部新增约 44dp 自适应明暗、可收起的控制条，点击实例胶囊可从 `/_dshx/api/instances` 拉取全部运行中实例并在当前 WebView 内无重启原地秒切，同时支持一键刷新与返回控制台。

### 体验优化

- **手机端控制台极简 UI 升级**：重塑亮/暗双色视觉层级；多运行中实例顶部新增横向快切胶囊条；运行中卡片整卡可点直达并从可启动列表中去重已运行实例；设置页按偏好、连接链路、已保存主机与设备分组并折叠自定义地址输入；原生配对页主推「扫码配对」并默认折叠手动表单。
- **浏览器 PWA 悬浮胶囊优化**：挂载后自动显示当前实例短名与多实例计数角标，在原生 App WebView 内自动避让顶部导航条。

### 问题修复

- **修复 Android 竖屏扫码与二维码识别**：新增锁死竖屏并开启 `TRY_HARDER`、`MIXED_SCAN` 与连续自动对焦的原生扫码页 `QrScanActivity`，同时将配对二维码内容压缩为紧凑 `#pair=<code>` + `ECC L` 低密度矩阵。
- **修复移动端原生覆盖层跟踪规则**：锚定 `mobile/.gitignore` 规则以防止误忽略 `mobile/native/android/` 源码。

### 其他变更

- 核心包 `dsh-x-core` 升至 `0.2.1-rc.2`（桌面 Electron 外壳保持 `0.2.0`）。

Full Changelog: [v0.2.1-rc.1...v0.2.1-rc.2](https://github.com/yyh-001/DSH-X/compare/v0.2.1-rc.1...v0.2.1-rc.2)

## English

### New Features

- **Native Android Notifications Linked with `dsh-x-desktop-notify`**: Add a background foreground-sync service (`NoticeSyncService`) and `/_dshx/api/notices` API with separate high-priority approval and task-completion channels, tap-to-open directly into the target DSH instance, plus a toggle and test button in Settings.
- **Native WebView Switcher Bar & Instance Sheet**: Add a compact ~44dp adaptive light/dark, collapsible top control bar to `DshWebViewActivity` with a bottom-sheet instance switcher backed by `/_dshx/api/instances` for instant zero-restart switching between running instances, page reload, and one-tap return to console.

### Improvements

- **Minimalist Mobile Console UI**: Refresh light/dark visual hierarchy, add a horizontal quick-switch strip when multiple instances are running, make running cards directly tappable while deduplicating running entries from the launch list, streamline Settings sections with collapsible custom endpoint input, and prioritize QR scanning in native pairing mode.
- **PWA Floating Pill Polish**: Automatically show the active instance short name and running count badge on mount in browser PWA mode, while hiding automatically inside the native WebView bar.

### Bug Fixes

- **Portrait QR Scanning & Compact Pairing Codes**: Add portrait-locked `QrScanActivity` with `TRY_HARDER`, `MIXED_SCAN`, and continuous autofocus, and compact pairing QR payloads to `#pair=<code>` with `ECC L`.
- **Android Native Overlay Git Tracking**: Anchor `mobile/.gitignore` patterns so `mobile/native/android/` sources are properly tracked.

### Chores

- Bump `dsh-x-core` to `0.2.1-rc.2` (the Electron desktop shell stays at `0.2.0`).
