`0.2.0` 汇总了 `0.1.26` 之后的全部更新：新增手机远程访问与公网穿透（含手机版 PWA）、实例与配置拆分、Computer Use 电脑操作、在线插件与技能市场、SSH / WSL 远端实例管理，以及多窗口标签无刷新拖放迁移。rc 通道用户会自动转回稳定通道。

### 新增功能

- 新增「远程 → 手机访问」与 DSH-X 手机版 PWA：支持一键开启手机访问、5 分钟一次性配对码与扫码授权、设备重命名与即时吊销、多主机/多链路测速选路，可在手机端查看日志、启停并进入桌面端 DSH 实例；内置 Cloudflare 外网穿透（临时体验域名、自建 Worker、加密保存的 Tunnel Token 与边缘节点优选）及区分临时/固定 HTTPS 域名的 PWA 安装引导（#124）。
- 实例与配置拆分：启动项改为「实例 × 配置」组合，插件的装、卸、升级与技能目录统一收进实例管理，支持导出导入镜像并跟随上游更新，配置页专注于开关与用户目录数据（感谢 @Arrosam）。
- 新增 Computer Use 电脑操作能力（`dsh-x-computer-use`）：由外壳持有桌面权限，默认启用，支持应用级首次授权、全局快捷键 `Ctrl+Alt+Backspace` 急停与操作审计（#113）。
- 实例详情的插件、MCP 与技能页签升级为「已安装 / 精选 / 市场」三签布局，支持在线市场浏览、搜索、分类筛选与一键安装；DSH-X 精选插件清单接入多镜像自动回退（`gh-proxy` / `ghfast` / `jsDelivr`）并提供中英双语信息（#123）。
- 支持 SSH 与 WSL 远端实例管理：新增远端连接管理与连接向导，本地界面可通过 WSL 远端 `dsh-x-core` 管理启动项、版本与 Profile（#103、#109）。
- 支持多实例独立窗口与标签跨窗口拖出、合并及无刷新迁移（感谢 @Shangshui0302）。
- macOS 与 Linux `.deb` 版本检测到新外壳安装包时首页直接提示下载（#123）；启动项编辑框支持一键设置 `DSH_HOME` 环境变量（#119）；Profile 备份支持过期清理与手动删除（#107）；核心支持独立运行与令牌鉴权（#101）。

### 体验优化

- 首页启动项卡片恢复独立编辑按钮与双列编辑弹窗，统一「编辑启动项」与「添加实例 → 自定义」的弹窗宽度、富下拉选择器及图标选择浮层样式；合并打开按钮并优化开窗下拉交互。
- 手机访问收口进「远程 → 手机访问」标签，精简为一开关、自动出码与折叠式高级设置；实例配置弹窗打开期间展示居中加载动画，移除首页启动项鼠标悬浮灰底；启动项日志不再显示 120 KB 截断提示。
- 界面术语统一调整为「实例」与「配置」，动画全面尊重系统「减少动态效果」；精简前后端与 Electron 外壳结构并优化磁盘占用缓存（#123）。

### 问题修复

- 修复下拉菜单下方空间不足时先弹出再向上翻转闪动、实例弹窗滚动条在 macOS 下压住右侧卡片按钮、以及「远程」等标签页文字未居中的问题。
- 修复实例「配置」页切换 DSH 版本或改名保存报错并补显式「保存」按钮；切换版本后自动停掉旧进程，支持已停止实例回退，并在首页列出无启动项的运行实例（#123）。
- 禁止将 `dsh` 用户目录与版本目录设在安装目录内（#119）；启动项卡片与目录下拉遇到路径形态脏名时回落短名并补回「管理目录」入口（#122）。
- 修复管理页窗口从托盘重建弹原生错误框（#117）、已登录管理页跳回令牌地址黑屏、深色下开标签闪白屏、Windows 拖标签预览窗高度累加、MCP / 技能双列卡片行高重叠及选择 Profile 弹窗按钮被推出视口（#106）。
- 修复安全启动恢复/还原补丁层与插件、macOS 系统默认语言识别、中文用户名下 `node.cmd` 路径读取、WSL 固定端口与乱码、`rc` 通道核心更新与黑名单长期拦截、英文界面残留中文及 `Esc` 关弹窗等问题（#123）。
- 放宽插件市场全量索引拉取超时并加入并发去重与自动重试；右键菜单插件撤出桌面增强，交回 dsh 自带菜单（#110）；保持 Electron 44.7.0 并在 Linux 上暂停跨窗迁移（#115）。

### 其他变更

- 外壳与核心版本统一升至 `0.2.0`，同时发布三平台安装包与跨平台核心包 `dsh-x-core`；rc 通道用户将自动转回稳定通道。
- 移除独立的 npm CLI 包装包（`@yyh001/dsh-x`），只保留 `dsh-x-core`；撤下实例市场，导入实例只收实例文件或 GitHub 仓库。
- macOS 最低版本仍是 13（Electron 44 / Chromium 152 的要求）。

## English

`0.2.0` collects all changes since `0.1.26`: Mobile Remote Access & Cloudflare Tunnel with a mobile PWA, the Instance × Profile split, Computer Use desktop control, in-app Plugin & Skills marketplaces, SSH / WSL remote instance management, and seamless multi-window tab drag-and-drop. Users on the rc channel return to the stable channel automatically.

### New Features

- Add **Remote → Mobile Access** and the DSH-X mobile PWA: one-click toggle, 5-minute one-time pairing codes and QR scanning, device renaming and instant revocation, multi-host/multi-route latency selection, plus remote log viewing and instance start/stop/open; includes built-in Cloudflare Tunnel support (Quick Tunnels, Custom Worker, encrypted Named Tunnel Tokens, edge IP probing) and origin-aware PWA install guidance (#124).
- Split Instances from Profiles: launch entries now pair an Instance with a Profile; plugin install/remove/upgrade and per-instance skills live inside Instances with export/import and upstream updates, while Profiles focus on toggles and user directory data (thanks @Arrosam).
- Add Computer Use (`dsh-x-computer-use`): the shell holds desktop permissions, enabled by default with per-app first-use authorization, a global `Ctrl+Alt+Backspace` emergency stop shortcut, and an action audit log (#113).
- Upgrade Plugins, MCP, and Skills in instance details to a three-tab layout (Installed / Curated / Market) with live browsing, search, category filters, and one-click install; DSH-X curated plugins support automatic multi-mirror fallback (`gh-proxy`, `ghfast`, `jsDelivr`) and English metadata (#123).
- Add SSH and WSL remote instance management with a connection manager and setup wizard; local UI can manage launch items, versions, and profiles through remote WSL `dsh-x-core` (#103, #109).
- Support multi-instance standalone windows and cross-window tab detaching, merging, and reload-free migration (thanks @Shangshui0302).
- Prompt macOS and Linux `.deb` users on the home page when a newer shell installer is available (#123); add a toggle to set `DSH_HOME` in Edit Launch (#119); add expiry cleanup and manual deletion for profile backups (#107); allow running the core standalone with token authentication (#101).

### Improvements

- Restore the dedicated edit button and two-column Edit Launch dialog on home cards, aligning dialog width, in-app rich dropdown pickers, and icon picker styling across Edit Launch and Add Instance (Custom); consolidate the open button and dropdown menu.
- Place Mobile Access under **Remote → Mobile Access** with a single toggle, auto-generated QR code, and collapsible Advanced Settings; show a centered spinner while opening the instance dialog, remove full-row gray hover backgrounds on home cards, and remove the 120 KB truncation notice from launch logs.
- Standardize UI terminology around "Instances" and "Profiles", respect reduced-motion preferences across animations, streamline backend/frontend/shell architecture, and harden disk-usage caching (#123).

### Bug Fixes

- Fix dropdown panels flashing downward before flipping upward when viewport space below is limited, scrollbars in the instance dialog overlapping right-column cards on macOS, and uncentered tab labels (including the Remote → Mobile Access tab).
- Fix errors when saving version or name changes in the instance **Config** tab with an explicit **Save** button; stop the previous DSH process on version change, allow stopped instances to roll back, and list running instances without launch items on the home page (#123).
- Disallow setting the `dsh` user directory or version directory inside the DSH-X installation directory (#119); fall back to short names when a launch card or directory picker stores a raw path and restore Manage Directories (#122).
- Fix native error dialogs when recreating the manager window from the tray (#117), token-redirect black screens, white flashes on dark-mode tab open, growing preview height on Windows tab drags, overlapping MCP/Skills grid rows, and off-screen action buttons in the Profile picker (#106).
- Fix Safe Start patch-layer/plugin restore, macOS system-language detection from Finder/Dock, `node.cmd` runtime lookup under non-ASCII Windows usernames, per-directory WSL pinned ports and error encoding, `rc`-channel core updates with expiring failure blacklists, remaining Chinese text in English mode, and `Esc` closing dialogs (#123).
- Increase full plugin market index fetch timeouts with request deduplication and retry; remove the context menu plugin from Desktop Enhance to defer to dsh's built-in menu (#110); stay on Electron 44.7.0 and disable cross-window tab migration on Linux (#115).

### Chores

- Bump both shell and core versions to `0.2.0` and publish installers for all three platforms alongside `dsh-x-core`; rc channel users automatically return to the stable channel.
- Remove the standalone npm CLI wrapper (`@yyh001/dsh-x`), keeping only `dsh-x-core`; remove the instance marketplace so instance imports accept only `.dspack` files or GitHub repositories.
- macOS minimum version remains 13 (required by Electron 44 / Chromium 152).
