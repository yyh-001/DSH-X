`0.2.0` 汇总了 `0.1.26` 之后的全部更新：实例与配置拆分、Computer Use 电脑操作、在线插件与技能市场、SSH / WSL 远端实例管理，以及多窗口标签无刷新拖放迁移。rc 通道用户会自动转回稳定通道。

### 新增功能

- 实例与配置拆分：启动项改为「实例 × 配置」组合，插件的装、卸、升级与技能目录统一收进实例管理，支持导出导入镜像并跟随上游更新，配置页专注于开关与用户目录数据（感谢 @Arrosam）。
- 新增 Computer Use 电脑操作能力（`dsh-x-computer-use`）：由外壳持有桌面权限，默认启用，支持应用级首次授权、全局快捷键 `Ctrl+Alt+Backspace` 急停与操作审计（#113）。
- 实例详情的插件、MCP 与技能页签升级为「已安装 / 精选 / 市场」三签布局，支持在线市场浏览、搜索、分类筛选与一键安装；DSH-X 精选插件清单接入多镜像自动回退（`gh-proxy` / `ghfast` / `jsDelivr`）。
- 支持 SSH 与 WSL 远端实例管理：新增远端连接管理与连接向导，本地界面可通过 WSL 远端 `dsh-x-core` 管理启动项、版本与 Profile（#103、#109）。
- 支持多实例独立窗口与标签跨窗口拖出、合并及无刷新迁移（感谢 @Shangshui0302）。
- 启动项编辑框支持一键将所选用户目录设为系统用户环境变量 `DSH_HOME`（#119）；Profile 备份支持过期清理与手动删除（#107）。
- 核心支持独立运行，新增管理页令牌鉴权与能力检测（#101）。

### 体验优化

- 首页启动项卡片恢复独立编辑按钮与双列编辑弹窗，统一「编辑启动项」与「添加实例 → 自定义」的弹窗宽度、富下拉选择器及图标选择浮层样式；合并打开按钮并优化开窗下拉交互。
- 实例配置弹窗打开期间展示居中加载动画，避免数据就绪前短暂空白；移除首页启动项鼠标悬浮时的整行灰底；已安装插件更新按钮并入版本号旁；界面动画全面尊重系统「减少动态效果」。
- 界面术语统一调整为「实例」与「配置」；备份弹窗改为表格展示，设置导航收口为「高级」。

### 问题修复

- 修复下拉菜单下方空间不足时先弹出再向上翻转闪动的问题，首帧前即按实际高度确定展开方向。
- 修复实例详情弹窗等列表滚动条在 macOS 下压住右侧卡片边缘与按钮的问题，以及标签页文字折行时未在组件内居中的问题。
- 禁止将 `dsh` 用户目录与版本数据目录设在 DSH-X 安装目录内，防止升级或卸载启动器时误删数据（#119）。
- 修复管理页窗口被系统销毁后从托盘重建弹出原生错误框（#117）、已登录管理页被跳回令牌地址导致黑屏，以及深色主题下打开标签页闪白屏的问题。
- 修复 Windows 下拖动标签预览窗口高度累加变长、MCP 与技能双列卡片行高压缩重叠、选择 Profile 弹窗插件多时「用它」按钮被推出视口（#106）等问题。
- 放宽插件市场全量索引拉取超时并加入并发去重与自动重试；修复精选清单分支指向、插件客户端 `ctx.locale.bind` 取词及大肥鱼歪头大小眼问题。
- 右键菜单插件撤出桌面增强，右键行为交回 dsh 自带菜单（#110）；回退 Electron 44.7.1 并在 Linux 上暂停跨窗迁移以保持原生兼容（#115）。

### 其他变更

- 外壳与核心版本统一升至 `0.2.0`，同时发布三平台安装包与跨平台核心包 `dsh-x-core`；rc 通道用户将自动转回稳定通道。
- 移除独立的 npm CLI 包装包（`@yyh001/dsh-x`），只保留 `dsh-x-core`；撤下实例市场，导入实例只收实例文件或 GitHub 仓库。
- macOS 最低版本仍是 13（Electron 44 / Chromium 152 的要求）。

## English

`0.2.0` collects all changes since `0.1.26`: the Instance × Profile split, Computer Use desktop control, in-app Plugin & Skills marketplaces, SSH / WSL remote instance management, and seamless multi-window tab drag-and-drop. Users on the rc channel return to the stable channel automatically.

### New Features

- Split Instances from Profiles: launch entries now pair an Instance with a Profile; plugin install/remove/upgrade and per-instance skills live inside Instances with export/import and upstream updates, while Profiles focus on toggles and user directory data (thanks @Arrosam).
- Add Computer Use (`dsh-x-computer-use`): the shell holds desktop permissions, enabled by default with per-app first-use authorization, a global `Ctrl+Alt+Backspace` emergency stop shortcut, and an action audit log (#113).
- Upgrade Plugins, MCP, and Skills in instance details to a three-tab layout (Installed / Curated / Market) with live browsing, search, category filters, and one-click install; DSH-X curated plugins support automatic multi-mirror fallback (`gh-proxy`, `ghfast`, `jsDelivr`).
- Add SSH and WSL remote instance management with a connection manager and setup wizard; local UI can manage launch items, versions, and profiles through remote WSL `dsh-x-core` (#103, #109).
- Support multi-instance standalone windows and cross-window tab detaching, merging, and reload-free migration (thanks @Shangshui0302).
- Add a toggle in Edit Launch to set the chosen user directory as the user `DSH_HOME` environment variable (#119); add expiry cleanup and manual deletion for profile backups (#107).
- Allow running the core standalone with token authentication and capability detection (#101).

### Improvements

- Restore the dedicated edit button and two-column Edit Launch dialog on home cards, aligning dialog width, in-app rich dropdown pickers, and icon picker styling across Edit Launch and Add Instance (Custom); consolidate the open button and dropdown menu.
- Show a centered loading spinner while opening the instance dialog to avoid a blank flash, remove full-row gray hover backgrounds on home launch cards, move the plugin update button next to the version label, and respect reduced-motion preferences across animations.
- Standardize UI terminology around "Instances" and "Profiles", turn the backup dialog into a compact table, and group advanced settings under "Advanced".

### Bug Fixes

- Fix dropdown panels flashing downward before flipping upward when viewport space below is limited by computing placement direction before the first paint.
- Fix scrollbars in the instance details dialog overlapping right-column cards and action buttons on macOS, and center single- and multi-line tab labels inside tab buttons.
- Disallow setting the `dsh` user directory or version data directory inside the DSH-X installation directory to prevent data loss on upgrade or uninstall (#119).
- Fix native error dialogs when recreating the manager window from the tray (#117), black screens from token redirects on already authenticated sessions, and white flashes when opening tabs in dark mode.
- Fix growing preview window height during Windows tab drags, overlapping rows in two-column MCP and Skills card grids, and the "Use" button being pushed off-screen when a profile has many plugins (#106).
- Increase full plugin market index fetch timeouts with request deduplication and automatic retry; fix curated manifest branch targeting, `ctx.locale.bind` lookups in plugin clients, and mascot eye alignment when tilted.
- Remove the context menu plugin from Desktop Enhance to defer to dsh's built-in menu (#110); stay on Electron 44.7.0 and disable cross-window tab migration on Linux for native compatibility (#115).

### Chores

- Bump both shell and core versions to `0.2.0` and publish installers for all three platforms alongside `dsh-x-core`; rc channel users automatically return to the stable channel.
- Remove the standalone npm CLI wrapper (`@yyh001/dsh-x`), keeping only `dsh-x-core`; remove the instance marketplace so instance imports accept only `.dspack` files or GitHub repositories.
- macOS minimum version remains 13 (required by Electron 44 / Chromium 152).
