> 0.1.23 和 0.1.24 从未公开发布，本版包含它们的全部改动。

### 新增功能

- 桌面通知：dsh 一轮结束、工具等你确认时发系统通知，正文是这一轮的任务原话（例如「任务已完成」+「任务：打开浏览器登录 b 站」）。
- 右键菜单：会话行、工作区行、正文选中文字、链接和输入框各有一套右键菜单；颜色跟 dsh 主题走。
- 侧栏浏览器：智能体可以直接操作右侧栏的官方 Browser（读页面、点击、输入、截图）；DSH-X 里官方右栏浏览器改用原生 webview，登录态正常保留。
- 插件桌面 API：插件可以通过本机接口调系统通知、打开链接、写剪贴板、弹文件对话框。
- 桌面增强：设置 → 常规 新增一块「桌面增强」，右侧「一键安装」把上面三个插件装进当前环境，装完按钮变「一键卸载」，卸载前会确认；装完的插件也可以在 dsh 插件页单独开关。
- 启动项日志：启动项每行新增「日志」按钮，能看本次启动的耗时构成（按插件排序）和原始日志，支持复制、导出、清空。
- 内置浏览器设置并入设置 → 常规：忽略证书校验、清除浏览器缓存 / 数据都在这一页，不再单开「浏览器控制」分类。
- 桌面端系统开关（设置 → 常规 → 系统）：Chrome 硬件加速、自动下载 DSH-X 更新、任务通知、通知声音、关闭窗口时隐藏到托盘、保持电脑运行。任务通知只管实例启动失败 / 意外退出，插件通知由插件自己的开关控制。
- 跑 dsh 可以改用系统安装的 Node，也可以手动指定路径。
- 启动项支持项目内的 `.dsh` 目录，以及从已有 Profile 复制一份新环境。
- 点「启动」先打开启动进度页，就绪后自动跳进实例。
- Linux 增加 deb 安装包：装进系统菜单，可以用 apt 卸干净；deb 版不支持外壳自更新。
- 新增第二套整合包「桌面工作台」：右侧栏工作台、Git 工作树、定时任务、已归档对话、提示音，外加 agent-browser 与 electron 两份技能。
- 启动项升级前检查已装插件的版本兼容性，不兼容时列出插件，并给出一段可复制的修复提示词。
- 启动项选 Profile 改成三栏选择窗（用户目录 / Profile / 这个环境里装了什么）；桌面增强默认关。

### 体验优化

- 通知更简洁：去掉正文里的大图，标题不再重复应用名，失败时正文多一行错误原因。
- 正常启动不再弹「DSH 已就绪」，只有启动失败和意外退出才提醒。
- 应用图标改成更圆润的圆角，任务栏、开始菜单和通知里的图标不再棱角分明。
- 标签条和启动进度页跟随实例；切主题、改外观即时同步，不用重启。
- 插件启动体检与实例启动耗时记录，配合启动项日志排查启动慢。
- 落地页下载按钮按系统选择，整块可点；文案去掉「轻量」，改成跨平台。
- mac 没有证书时用 ad-hoc 签名，避免 Gatekeeper 提示「已损坏」。
- 插件诊断搬到启动项日志顶部：同一个包只列一次，标出「插件版本不兼容」；有没看过的诊断时日志图标点亮红点，不再自动弹「插件版本不兼容」升级窗。
- 启动项日志按本机时区显示时间，重开时正文和耗时构成立即出现；过滤 `model listing` 成功摘要，`token=` 打码。
- 启动过渡页只保留进度，不再显示步骤条和「启动完成后这个页面会自动打开 dsh」。

### 问题修复

- 修复没装 Node.js 的机器上安装插件失败（npm 的后装脚本找不到 node）。
- 有实例在跑时点关闭或退出，会先问一句再停止，不再直接清掉进程。
- 页面里的下载（比如导出启动日志）不再静默消失：弹保存框，完成或失败都有提示。
- 修正目录下拉的过期提示，以及项目环境工作目录的路径判断。
- 修复标签形态左上角回主页图标和「DSH-X」字标重叠、折行。
- 点程序坞图标回到之前打开的标签页，不再跳回主页。
- 窗口跑到屏幕外时，唤回会把它搬回主屏。
- Web 绑定选局域网后，其他设备能访问，复制的链接直接是局域网地址。
- 停止实例时先终止进程树再断开生命周期连接；实例自重启后自动重新接管并刷新认证令牌。
- 修复兼容性检查合并后管理页白屏。

### 其他变更

- 更新通道跟着当前版本走，撤掉「预发布」开关；自动下载更新只负责下载，安装仍要手动点「更新」。
- README 与落地页重排；删掉 Rust 安装引擎与 Inno 脚本，打包只剩 electron-builder。
- 自重启用例按 PID + 心跳判活，避免 Windows 上 PID 复用误判。
- 核心版本升到 0.1.25；外壳仍是 0.1.24，安装包文件名不变。

Full Changelog: [v0.1.22...v0.1.25](https://github.com/yyh-001/DSH-X/compare/v0.1.22...v0.1.25)

## English

> 0.1.23 and 0.1.24 were never published; this release includes all of their changes.

### New Features

- Desktop notifications: a system notification when a turn ends or a tool waits for your approval, with the task text from that turn (for example "Task completed" + "Task: open the browser and sign in to bilibili").
- Context menus: separate right-click menus for session rows, workspaces, selected text, links and inputs, coloured with the dsh theme.
- Sidebar browser: the agent can drive the official right-sidebar Browser (read pages, click, type, take screenshots); the official browser now runs in a native webview inside DSH-X and keeps your logins.
- Desktop API for plugins: plugins can raise system notifications, open links, write to the clipboard and show file dialogs through a local endpoint.
- Desktop enhancements: a new block in Settings → General installs the three plugins above into the current environment with one click; the button then becomes "Uninstall" (with a confirmation), and each plugin can also be toggled in the dsh plugin page.
- Launch logs: every launch entry has a Log button with the startup timing breakdown (sorted by plugin) and the raw log, with copy, export and clear.
- Built-in browser settings moved into Settings → General: certificate validation and cache / data clearing live there instead of a separate "Browser control" category.
- Desktop system switches (Settings → General → System): Chrome hardware acceleration, automatic DSH-X update downloads, task notifications, notification sound, close-to-tray, keep the computer awake. Task notifications cover only startup failures and unexpected exits; plugin notifications have their own switch.
- Run dsh with the system-installed Node, or point at a specific binary.
- Launch entries can use a project-local `.dsh` directory or copy an existing profile.
- Start now opens a boot progress page and jumps into the instance when it is ready.
- Linux gains a deb package: menu entry, clean `apt remove`; the deb build cannot self-update the shell.
- A second built-in pack, "Desktop Workbench": right-sidebar workbench, Git worktrees, cron jobs, archived conversations, notification sounds, plus the agent-browser and electron skills.
- Launch entries check installed plugins for version compatibility before an upgrade, listing incompatible plugins and offering a copyable prompt to fix them.
- Picking a Profile for a launch entry now uses a three-column picker (user directory / Profile / what the environment contains); desktop enhancements are off by default.

### Improvements

- Cleaner notifications: no large body image, the title no longer repeats the app name, and failures add an error line.
- A normal start no longer raises a "DSH is ready" notification; only startup failures and unexpected exits do.
- The app icon now has softer, rounder corners on the taskbar, in the Start menu and in notifications.
- The tab strip and boot progress page follow the instance; theme and appearance changes apply immediately.
- Plugin startup health checks and instance startup timings, surfaced through the launch log.
- The landing page download button picks your platform and is clickable as a whole.
- ad-hoc signing on macOS when no certificate is configured, avoiding Gatekeeper's "damaged" warning.
- Plugin diagnostics now sit at the top of the launch log, one row per package with an "incompatible plugin versions" tag; the log icon shows a dot for unread diagnostics, and the automatic incompatible-plugin prompt is gone.
- Launch log timestamps follow the local timezone; reopening shows the text and timing breakdown immediately; successful `model listing` summaries are filtered out and `token=` is masked.
- The boot progress page keeps the progress indicator only; the step bar and the "this page will open dsh when ready" line are gone.

### Bug Fixes

- Fix plugin installation failing on machines without Node.js installed (npm lifecycle scripts could not find node).
- Closing or quitting while instances are running now asks first instead of killing them.
- In-page downloads (for example exporting launch logs) no longer vanish silently: a save dialog appears and the result is reported.
- Fix stale hints in the directory picker and working-directory resolution for project environments.
- Fix the home icon and "DSH-X" wordmark overlapping and wrapping in the tab layout.
- Clicking the dock icon returns to the previously open tab instead of the home page.
- Bringing back an off-screen window now moves it onto the main display.
- When Web binding is set to LAN, other devices can connect and the copied link uses the LAN address.
- Stopping an instance now terminates the process tree before closing the lifecycle connection; after an instance restarts itself, DSH-X re-attaches and refreshes the auth token automatically.
- Fix the manager page going blank after the compatibility-check merge.

### Chores

- The update channel follows the current version; the prerelease switch is gone. Automatic updates only download — installing still needs the Update button.
- README and landing page restructured; the Rust installer engine and Inno scripts are gone, packaging is electron-builder only.
- Self-restart detection now uses PID plus heartbeat, avoiding false positives from Windows PID reuse.
- Core version bumped to 0.1.25; the shell stays 0.1.24 and the installer filename is unchanged.
