作为 `0.2.1` 系列的首个候选版本，本版本汇总了自 `v0.2.0` 以来的主要变更。

### 新增功能

- 新增 DSH-X Android 原生 App 壳（Capacitor 8）：复用手机控制台界面，内置离线扫码配对、`AndroidKeyStore` 加密存储设备凭证、绕过混合内容限制的局域网/隧道并发测速选路，以及基于会话桥接（`/_dshx/api/session/bootstrap`）的原版 DSH 全屏 WebView。
- 新增「数据」页与跨用户目录静态会话管理、归档中心和空间分析，并支持 WSL / SSH 远端用户目录与按设备筛选（#127）。
- MCP 页面支持读取并管理 profile `cordis.patch.yml` 中手写或外部工具写入的 MCP 服务器条目，支持按 `id` 精确启停、检测与删除，并对无法表单改写的条目给出只读提示。

### 体验优化

- 优化手机端远程控制台多链路测速与原生容器切换体验。

### 问题修复

- 修复新建实例保存 DSH 版本时报错的问题（@Arrosam，#129）。
- 手机配对链接参数从 `?pair=` 迁至 `#pair=`（向下兼容旧链接），避免一次性配对码进入代理访问日志与 `Referer`。
- 加固手机端静态壳的符号链接逃逸校验与响应安全头（`no-referrer`、`X-Frame-Options: DENY`、入口页 `no-store`），并为 WebSocket 代理连接启用 TCP Keep-Alive 与上游建连超时保护。
- 修复 `cordis.patch.yml` 中裸 `-` 序列条目的格式识别误判。

### 其他变更

- 核心包 `dsh-x-core` 升至 `0.2.1-rc.1`（桌面 Electron 外壳保持 `0.2.0`）；新增 Android APK 自动构建、正式签名与验包 CI 流水线。
- 重设计中英文 README 与深浅自适应首屏主图，补充英文界面截图及实例/用户目录/启动项说明（#127）。

Full Changelog: [v0.2.0...v0.2.1-rc.1](https://github.com/yyh-001/DSH-X/compare/v0.2.0...v0.2.1-rc.1)

## English

### New Features

- Add the DSH-X Android native app shell (Capacitor 8): reuses the mobile console UI with built-in offline QR pairing, `AndroidKeyStore`-encrypted token storage, mixed-content-free LAN/tunnel concurrent route probing, and a fullscreen official DSH WebView backed by `POST /_dshx/api/session/bootstrap`.
- Add the **Data** page with cross-profile static session management, archive center, storage breakdown, and WSL/SSH remote user-directory & device filtering (#127).
- Support listing and managing external or hand-written MCP server entries in a profile's `cordis.patch.yml`, with `id`-targeted toggle/probe/delete actions and read-only badges for raw-only entries.

### Improvements

- Polish multi-route latency probing and native container switching in the mobile remote console.

### Bug Fixes

- Fix an error when saving the DSH version while creating a new instance (@Arrosam, #129).
- Move mobile pairing URL payloads from `?pair=` to `#pair=` (while remaining backward-compatible with `?pair=`) so one-time pairing codes never enter proxy access logs or `Referer` headers.
- Harden mobile static shell serving with `realpath` symlink-escape checks and security headers (`no-referrer`, `X-Frame-Options: DENY`, `no-store` on `index.html`), and enable TCP keep-alive plus upstream connect timeout on WebSocket proxy upgrades.
- Fix YAML entry-list detection for bare `-` sequence items in `cordis.patch.yml`.

### Chores

- Bump `dsh-x-core` to `0.2.1-rc.1` (the Electron desktop shell remains at `0.2.0`); add an Android APK build, release-signing, and verification CI workflow.
- Redesign the Chinese and English READMEs with adaptive hero artwork, English screenshots, and Docker-style explanations of instances, user directories, and launches (#127).
