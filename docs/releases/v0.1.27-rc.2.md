`0.1.27-rc.2` 是 `0.1.27` 的第二版预发布：新增 WSL / SSH 远端连接与远端 dsh 管理，启动项可以直接跑在远端；同时收口了连接页和添加启动项的界面。外壳有改动，rc 通道会收到新的安装包。

### 新增功能

- **WSL / SSH 远端**：设置 → 远程里管理连接（WSL 发行版或 SSH 主机），支持私钥 / 密码 / agent、SSH config 导入、主机指纹首次信任与变更拦截，凭据加密保存。
- **启动项跑在远端**：连接选好后，版本、Profile、插件、整合包和实例都交给远端的 `dsh-x-core` 管理；远端首次使用时会自动安装 core 和符合版本要求的 Node，SSH 上的 dsh 页面通过实例端口转发在本机窗口打开。
- **远端日志**：远端 dsh 的输出通过日志流回本机启动项日志，启动、停止和退出现在都能在同一个日志弹窗里看到。
- **添加启动项的远端引导**：新建 Profile 先选用户目录（本机目录或已保存的 WSL / SSH 连接），远端会自动建 Profile 和目录；从已有 Profile 复制时不再单独选设备，来源的三级选择窗（用户目录 / Profile / 内容）已经包含设备与目录。

### 问题修复

- 修复 SSH 远端 `@auto` 被当成版本号安装、远端 Node 版本过低、core 里 Node 包装不可执行导致 `Permission denied` 的问题。
- 修复 SSH 远端 dsh 启动后本机打不开的问题：为每个远端实例单独建立 SSH 端口转发。
- 修复添加启动项后进度页一直停在「准备启动」：SSH 启动项的进度页现在带合成用户目录，实例就绪后会自己跳进 dsh。
- 修复从选择窗打开「创建项目」弹窗后取消会直接掉回主页：现在取消会回到选择窗。
- 修复更新弹窗高度随版本说明长短变化：弹窗固定尺寸，正文在卡片内滚动。
- 修复设置 → 远程里重复出现的「未完成的连接」区块：失败连接已体现在设备列表的状态点上，该区块已移除。

### 其他变更

- README 增加 WSL / SSH 远端说明（中英文同步）。
- 外壳与核心版本都升到 `0.1.27-rc.2`，rc 通道会收到新的安装包。

## English

`0.1.27-rc.2` is the second preview of `0.1.27`: WSL / SSH remote connections and remote dsh management, so launch entries can run on a remote host, plus UI cleanup for the connections page and the add-launch dialog. The shell changed, so the rc channel receives a new installer.

### Features

- **WSL / SSH remotes**: manage connections under Settings → Remote (a WSL distro or an SSH host), with key / password / agent auth, SSH config import, host-key trust on first use with a hard stop on changes, and encrypted credentials.
- **Launch entries on remotes**: once a connection is chosen, versions, profiles, plugins, packs and instances are managed by the remote `dsh-x-core`; the first use installs the core and a suitable Node automatically, and an SSH-hosted dsh page opens locally through a per-instance port forward.
- **Remote logs**: output from the remote dsh is streamed back into the local launch log, so start, stop and exit are visible in the same log dialog.
- **Remote guided setup for new launch entries**: pick a user directory first (a local directory or a saved WSL / SSH connection); profiles and directories are created on the remote. When copying an existing profile, the device is no longer asked for separately — the three-column picker (user directory / profile / content) already contains the device and directory.

### Bug Fixes

- Fix SSH remotes trying to install `@auto` as a version, using an outdated remote Node, and failing with `Permission denied` when the Node wrapper in the core is not executable.
- Fix SSH-hosted dsh instances being unreachable locally: each remote instance now gets its own SSH port forward.
- Fix the boot progress page staying on "Preparing" for remote launch entries: it now carries the synthetic user directory and jumps into dsh when the instance is ready.
- Fix cancelling the "Create project" dialog opened from the environment picker dropping back to the home page; cancel now returns to the picker.
- Fix the update dialog changing height with the release notes: it now has a fixed size and scrolls its content.
- Remove the duplicated "Unfinished connections" block in Settings → Remote; failed connections are already shown by the status dot in the device list.

### Chores

- README now covers WSL / SSH remotes (Chinese and English).
- Shell and core versions are now `0.1.27-rc.2`; the rc channel receives a new installer.
