`0.1.27-rc.4` 是 `0.1.27` 的第四版预发布：实例与配置拆分重新回归，实例开始有独立窗口和独立技能目录，插件的装卸也搬到了实例页。

### 新增功能

- 实例与配置拆分重新合入：启动项 = 实例 × 配置，实例可导入导出、跟随上游更新（#118，@Arrosam）。
- 每个实例有独立技能目录，复制、导出和导入实例时技能跟着走。
- 实例页直接装卸、升级插件，配置页只保留插件开关和数据。
- 支持多实例独立窗口，标签可拖到其他窗口合并，页面迁移不重新加载（#114、#116，@Shangshui0302）。

### 体验优化

- 实例页页头改成一排动作按钮，新建实例时才弹窗问名字。
- 首页启动卡片与实例弹窗交互统一，插件、MCP、技能的管理收拢到同一处。
- 配置页补充说明，实例卡片改成和配置卡片同款。

### 问题修复

- 修复已登录后管理页在令牌地址和干净地址之间反复跳转、窗口黑屏的问题。
- 修复合盖休眠唤醒后管理页窗口被系统销毁、点托盘弹主进程异常框的问题（#117）。
- 修复新配置第一次启动没有装上实例插件的问题。
- 修复实例更新表单和导出校验的问题；实例详情页空插件提示与上游更新行不再错位。
- 修复 Windows 上拖动标签时标题预览窗口高度不断累加变长。
- 修复大肥鱼歪头时两只眼睛大小不一致。
- Linux 上切换实例打开方式被拒时，提示先关闭标签再重新打开。

### 其他变更

- 撤下实例市场，导入实例只接受实例文件或 GitHub 仓库；市场以后单独做。
- Electron 回到 44.7.0；Linux 暂时不提供跨窗标签拆合，只保留同窗排序和首次独立开窗。
- 每用户目录可用 `DSH_APP_DIR` 整个换掉，本机可以并排跑测试包。
- 外壳与核心版本都升到 `0.1.27-rc.4`，rc 通道会收到新的安装包。

## English

`0.1.27-rc.4` is the fourth preview of `0.1.27`: the instance/profile split is back, instances now get their own windows and skills folders, and plugin install/upgrade moved to the instance page.

### New Features

- The instance/profile split is back: a launch item is now instance × profile; instances can be imported, exported and follow upstream (#118, @Arrosam).
- Each instance has its own skills folder; skills travel with copied, exported and imported instances.
- Install, remove and upgrade plugins from the instance page; the profile page keeps only toggles and data.
- Multi-instance standalone windows: tabs can be dragged into other windows and pages migrate without reloading (#114, #116, @Shangshui0302).

### Improvements

- The instance page header is now a row of action buttons; the name is asked in a dialog when creating an instance.
- Home launch cards and instance dialogs share one interaction; plugin, MCP and skill management lives in one place.
- The profile page explains its options, and instance cards match profile cards.

### Bug Fixes

- Fix the manager page bouncing between the token and clean URLs after login, which left the window blank.
- Fix the manager window being destroyed after lid sleep/wake and a native error dialog appearing when clicking the tray (#117).
- Fix plugins not being installed on a new profile's first launch.
- Fix instance update form and export validation; empty-plugin hints and the upstream update row no longer misalign.
- Fix the tab title preview growing taller on every drag on Windows.
- Fix the mascot's eyes being different sizes when it tilts its head.
- On Linux, switching how an instance opens now explains that the tab must be closed and reopened.

### Chores

- Remove the instance marketplace; imports accept instance files or GitHub repos only. The marketplace will return separately.
- Electron is back on 44.7.0; Linux keeps same-window reordering and first-time standalone windows but not cross-window tab detach/merge.
- `DSH_APP_DIR` can replace the per-user folder so several test builds can run side by side.
- Shell and core versions are now `0.1.27-rc.4`; the rc channel gets new installers.
