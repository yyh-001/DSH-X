本版更新外壳的首次启动体验：核心下载窗口有实时进度、来源和正确的高度；核心内容与 `0.1.26-rc.2` 相同，没有功能变化。

### 体验优化

- 首启下载窗口显示实时进度：已下载 / 总大小 / 百分比，以及实际使用的下载源（npm 镜像或官方源）。
- 镜像元数据 6 秒超时就自动切到官方源；tarball 从镜像拉不动时，也会换另一个源的同版本重试。
- 解压阶段进度条保持满格，并明确提示「下载完成，正在解压（通常几秒）」，不再看起来从 0 重来。
- 窗口固定 480×280，不再出现滚动条；去掉取消按钮；网速再快也至少展示 1.2 秒。

### 问题修复

- 下载窗口的注入脚本有一处语法错误，导致进度、下载源和文案完全不更新、看起来像卡死。

### 其他变更

- 外壳版本 `0.1.26-rc.3`；核心版本号跟随发布（内容与 `0.1.26-rc.2` 相同）。
- macOS 最低版本仍是 13（Electron 44 / Chromium 152 的要求）。

## English

This release updates the shell's first-launch experience: the core download window now has live progress, a source label and a correct height. The core content is identical to `0.1.26-rc.2`; there are no functional changes.

### Improvements

- The first-launch download window shows live progress (downloaded / total / percent) and the actual download source (npm mirror or official registry).
- Mirror metadata times out after 6 seconds and falls back to the official registry; if the tarball cannot be fetched from one source, the same version is retried from the other.
- During extraction the progress bar stays full and clearly says "Download complete, unpacking (a few seconds)…" instead of appearing to restart from 0.
- The window is a fixed 480×280 with no scrollbar, the cancel button is gone, and it stays visible for at least 1.2 seconds even on fast connections.

### Bug Fixes

- A syntax error in the download window's injected script meant progress, source and status text never updated, so the window looked frozen.

### Chores

- Shell version `0.1.26-rc.3`; the core version follows the release (content identical to `0.1.26-rc.2`).
- macOS minimum remains 13 (required by Electron 44 / Chromium 152).

Full Changelog: [v0.1.26-rc.2...v0.1.26-rc.3](https://github.com/yyh-001/DSH-X/compare/v0.1.26-rc.2...v0.1.26-rc.3)
