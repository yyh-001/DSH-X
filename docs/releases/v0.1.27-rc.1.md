`0.1.27-rc.1` 是 `0.1.27` 的第一版预发布：新增配置备份管理，修复深色模式下打开标签页闪白和几个弹窗的布局问题。外壳有改动，rc 通道会收到新的安装包。

### 新增功能

- 配置备份管理（#107，感谢 @boillter 的建议）：每个 Profile 最多保留最近 10 份配置快照，超过 30 天的自动清理（最新一份始终保留）；打开备份窗或启动前快照时都会执行清理。备份列表每一行都能手动删除（先确认，只删这一份快照，不碰当前配置）。

### 问题修复

- 修复深色模式下打开内部标签页会闪一下白屏：标签页原生视图的底色改为和页面一致，独立窗口换页前也会先铺目标页底色。
- 修复「选择配置」弹窗底部空出一整行：状态提示为空时不再占高度，有提示时列表照常让出一行。
- 修复「添加启动项」弹窗滚动时「隔离方式」切档跟着字段一起滚走：切档条固定在上沿，字段区自己滚动。

### 体验优化

- 「配置备份与回退」弹窗简化：说明收成一行（完整细节看悬停提示），列表改成行间分隔线的表格，行里只显示时间、文件数量和操作，「立即备份」升为主按钮。
- 设置导航里的「高级设置」改名为「高级」。

### 其他变更

- 外壳与核心版本都升到 `0.1.27-rc.1`，rc 通道会收到新的安装包。
- 发布资产统一命名（`DSH-X-<版本>-<平台>-<架构>`），落地页下载直链跟着更新。
- 实例 / 配置拆分（#105）暂时从主线剥离，完整改动保留在 `pr105` 分支，后续继续完善；这一版仍沿用整合包 / Profile 的模型。

## English

`0.1.27-rc.1` is the first preview of `0.1.27`: profile backup management, a dark-mode white flash fix for tabs, and several dialog layout fixes. The shell changed, so the rc channel receives a new installer.

### Features

- Profile backup management (#107, thanks to @boillter for the suggestion): each profile keeps the latest 10 config snapshots, and snapshots older than 30 days are removed automatically (the newest one is always kept). Cleanup runs when the backup dialog opens and on the pre-launch snapshot. Each row can be deleted manually after confirmation; only that snapshot is removed, the current config is untouched.

### Bug Fixes

- Fix a white flash when opening an internal tab in dark mode: the native view now uses the page background, and the standalone window prepares the target page's background before navigating.
- Fix an empty row at the bottom of the "Choose profile" dialog: an empty status line no longer reserves height, and the list yields one row when a message appears.
- Fix the "Isolation" tab strip scrolling away with the fields in the "Add launch" dialog: the tab strip stays pinned while only the field area scrolls.

### Improvements

- The "Profile backups & rollback" dialog is simplified: the hint is one line (full details on hover), the list is a table with row separators showing only time, file count and actions, and "Back up now" is the primary button.
- The "Advanced settings" nav item is renamed to "Advanced".

### Chores

- Shell and core versions are now `0.1.27-rc.1`; the rc channel receives a new installer.
- Release assets use consistent names (`DSH-X-<version>-<platform>-<arch>`), and the landing page download links follow.
- The instance/profile split (#105) is temporarily detached from the main line and preserved on the `pr105` branch; this release keeps the pack/Profile model.
