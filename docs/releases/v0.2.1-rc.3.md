本预发布版本汇总了自 `v0.2.1-rc.2` 以来在 Android App 内更新、扫码配对与原生 WebView 界面上的更新。

### 新增功能

- **Android App 内更新**：设置页新增「应用版本」，首页横幅提示新版本，点一下即下载 APK 并调起系统安装；下载时显示进度，安装前校验 SHA-256，覆盖升级后已配对设备与登录状态保持不变。
- **扫码 / 深链自动配对**：原生扫码页识别到配对码后自动完成配对并直达控制台；带 `#pair=` 的配对链接在 App 内打开时同样自动配对，失败时留在配对卡片显示原因。

### 体验优化

- **原生 WebView 顶部导航栏重绘**：改用矢量图标与自适应深浅色的紧凑导航条，实例胶囊、刷新与「返回控制台」按钮的对齐和点击反馈统一。
- **连接失败页改为居中卡片**：红色警示图标配标题与通俗的原因说明，原始报错收进可折叠的等宽详情框，底部「返回控制台 / 重试」等宽按钮，深浅色都可读。
- **手机端控制台顶栏收紧**：顶栏留白、连接状态胶囊与图标按钮更紧凑，滚动时的毛玻璃层次更清晰。
- **远程高级设置 UI 修正**：保存按钮固定右对齐；隧道模式分段开关字重恢复正常，不再把 label 样式带到其他控件。

### 问题修复

- **旧版电脑端核心兼容兜底**：连接尚无 `/_dshx/api/session/bootstrap` 接口的旧核心（低于 `0.2.1-rc.1`）时，Android WebView 直接写入设备会话 Cookie 继续进入实例，不再显示连接失败。

### 其他变更

- 核心包 `dsh-x-core` 升至 `0.2.1-rc.3`（桌面 Electron 外壳保持 `0.2.0`），重新打包并签名的 Android APK 随本版本发布。

Full Changelog: [v0.2.1-rc.2...v0.2.1-rc.3](https://github.com/yyh-001/DSH-X/compare/v0.2.1-rc.2...v0.2.1-rc.3)

## English

This pre-release summarizes the changes since `v0.2.1-rc.2` to the Android app's in-app update, QR pairing, and native WebView UI.

### New Features

- **In-app Android updates**: Settings now has an **App Version** row and a home banner announces new versions; one tap downloads the APK and launches the system installer, with a progress indicator and a SHA-256 check before install. Existing pairing and sign-in survive an in-place upgrade.
- **Automatic QR and deep-link pairing**: After scanning a pairing QR code, the native scanner completes pairing and opens the console directly; pairing links carrying `#pair=` behave the same when opened in the app, and failures stay on the pairing card with a reason.

### Improvements

- **Redesigned native WebView top bar**: A compact vector-icon navigation bar that adapts to light and dark themes, with unified alignment and tap feedback for the instance pill, refresh, and back-to-console actions.
- **Connection-failure page as a centered card**: A red warning icon with a title and plain-language reason, the raw error tucked into a collapsible monospace details box, and equal-width **Back to console / Retry** buttons that read well in both themes.
- **Tighter mobile console header**: Less padding, a smaller connection pill and icon buttons, and clearer frosted-glass layering while scrolling.
- **Remote advanced settings UI fixes**: The save button now always sits at the right edge, and the tunnel mode segmented control returns to its normal font weight without leaking label styles into other controls.

### Bug Fixes

- **Fallback for older desktop cores**: When connecting to a core that predates the `/_dshx/api/session/bootstrap` endpoint (below `0.2.1-rc.1`), the Android WebView now writes the device session cookie itself and still opens the instance instead of showing a connection failure.

### Chores

- Bump `dsh-x-core` to `0.2.1-rc.3` (the Electron desktop shell stays at `0.2.0`); ship a rebuilt, signed Android APK with this release.
