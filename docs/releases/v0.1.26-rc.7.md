`0.1.26-rc.7` 是一次核心更新：修复「添加启动项」里目录下拉被长路径撑出弹窗的问题。外壳没有改动，rc 通道不会收到新的安装包。

### 问题修复

- 修复「添加启动项」的会话隔离档里，目录下拉中的长路径把整行撑出弹窗、超长部分不显示省略号、右侧下拉箭头也看不见的问题；现在按弹窗宽度截断并显示省略号，展开后仍能看到完整路径。

### 其他变更

- 核心版本升到 `0.1.26-rc.7`；外壳维持 `0.1.26-rc.6`，本次不重新出安装包。

## English

`0.1.26-rc.7` is a core-only update that fixes the target-directory dropdown in "Add launch" being pushed out of the dialog by long paths. The shell is unchanged, so the rc channel will not receive a new installer.

### Bug Fixes

- Fix the target-directory dropdown in "Add launch" (Session isolation) where a long path pushed the row past the dialog, hiding both the ellipsis and the caret; long values now truncate to the dialog width with an ellipsis, and the full path is still visible in the expanded options.

### Chores

- Core version is now `0.1.26-rc.7`; the shell stays at `0.1.26-rc.6`, so no new installer is produced.

Full Changelog: [v0.1.26-rc.6...v0.1.26-rc.7](https://github.com/yyh-001/DSH-X/compare/v0.1.26-rc.6...v0.1.26-rc.7)
