### 新增功能

- 新增「远程 → 手机访问」与 DSH-X 手机版网页控制台：支持一键开启手机访问、5 分钟一次性配对码与扫码授权、设备重命名与即时吊销、多主机/多链路测速选路，以及在手机端查看日志和启停、进入桌面端 DSH 实例（#124）。
- 手机访问内置 Cloudflare 外网穿透能力：支持临时体验域名、自建 Worker 与已有 Tunnel Token（密钥加密保存），并支持自定义公网 HTTPS 域名与边缘节点优选测速（#124）。
- 手机端新增区分临时域名与固定 HTTPS 域名的 PWA 安装引导：在临时 `*.trycloudflare.com` 域名下提醒更换固定域名避免重启失效，在固定 HTTPS 域名下提供原生安装或分步添加引导。
- macOS 与 Linux `.deb` 版本检测到新外壳安装包时，首页会直接给出下载更新提示（@Arrosam，#123）。
- 精选插件清单新增英文名称与简介，英文界面下直接展示英文信息（@Arrosam，#123）。

### 体验优化

- 将移动与远程访问迁入「远程 → 手机访问」标签并精简为一开关、自动出码与折叠式高级设置，减少日常配对与开隧道步骤。
- 精简前后端路由与 Electron 外壳结构，优化磁盘占用缓存（不落半截结果并限制内存条目数）与并发保存体验（@Arrosam，#123）。

### 问题修复

- 修复启动项卡片和用户目录下拉在名字被登记成完整路径时显示错乱的问题，回落短名并补回「管理目录」入口（#122）。
- 修复切换实例 DSH 版本后旧进程仍留在后台的问题，支持已停止实例回退，并将无启动项的运行实例一并列出在首页（@Arrosam，#123）。
- 修复安全启动恢复/还原无法放回补丁层与被摘插件、macOS 识别系统首选语言、中文用户名下 `node.cmd` 读取运行时路径及插件耗时统计偏差问题（@Arrosam，#123）。
- 修复 WSL 固定端口不生效、残留进程清理与报错乱码，以及 `rc` 通道核心更新与黑名单长期拦截问题（@Arrosam，#123）。
- 修复英文界面混入中文、切换语言后局部未重绘、弹窗无法按 `Esc` 关闭以及并发与资源泄漏问题（@Arrosam，#123）。

### 其他变更

- 核心（`dsh-x-core`）与 Electron 外壳同步升至 `0.1.27-rc.7`，本次包含外壳改动，发布后 `rc` 通道将同步收到新版安装包与核心包。
- 修正 CI 核心包发布与 `latest*.yml` 更新清单流程，并精简中英文 README 的远程与更新说明（@Arrosam，#123）。

Full Changelog: [v0.1.27-rc.6...v0.1.27-rc.7](https://github.com/yyh-001/DSH-X/compare/v0.1.27-rc.6...v0.1.27-rc.7)

## English

### New Features

- Add **Remote → Mobile Access** and the DSH-X mobile web console: one-click gateway toggle, 5-minute one-time pairing codes and QR scanning, device renaming and instant revocation, multi-host/multi-route latency selection, plus remote log viewing and instance start/stop/open actions (#124).
- Add built-in Cloudflare Tunnel support with Quick Tunnels, Custom Worker, or Named Tunnel Tokens (stored encrypted rather than in plaintext settings), alongside custom HTTPS URLs and edge IP probing (#124).
- Add origin-aware PWA install guidance on mobile that warns against installing expiring `*.trycloudflare.com` quick-tunnel URLs and provides native or step-by-step installation prompts on permanent HTTPS domains.
- Show a home-page prompt to download newer shell installers on macOS and Linux `.deb` builds (@Arrosam, #123).
- Add English titles and descriptions to the curated plugin manifest for English UI users (@Arrosam, #123).

### Improvements

- Move Mobile & Remote Access into **Remote → Mobile Access** and simplify it into a one-click toggle, auto-generated QR code, and collapsible Advanced Settings panel.
- Streamline backend, frontend, and Electron shell architecture, and harden disk-usage caching to avoid persisting partial scans and bound in-memory entries (@Arrosam, #123).

### Bug Fixes

- Fall back to short directory names when a launch card or User Directory picker contains a raw path string, and restore the Manage Directories entry (#122).
- Stop the previous DSH process when changing an instance version, allow stopped instances to roll back, and show running instances without launch items on the home page (@Arrosam, #123).
- Fix Safe Start recovery/restore not restoring patch layers and plugins, macOS system-language detection from Finder/Dock, `node.cmd` runtime lookup under non-ASCII Windows usernames, and plugin profiling attribution (@Arrosam, #123).
- Fix per-directory WSL pinned ports, stale process cleanup and error encoding, and `rc`-channel core updates with expiring failure blacklists (@Arrosam, #123).
- Fix remaining Chinese text in English mode, partial redraws on language switch, `Esc` closing dialogs, and concurrency/resource leaks (@Arrosam, #123).

### Chores

- Bump both `dsh-x-core` and the Electron shell to `0.1.27-rc.7`; the `rc` channel receives both new installers and the core package update.
- Fix CI core publishing and `latest*.yml` handling, and trim Remote/Update sections in the Chinese and English READMEs (@Arrosam, #123).
