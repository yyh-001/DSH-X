### 新增功能

- 新增 Computer Use 电脑操作能力（`dsh-x-computer-use`）：由外壳持有桌面权限，默认启用，支持应用级首次授权、全局快捷键 `Ctrl+Alt+Backspace` 急停与操作审计（#113）。
- 实例详情的插件、MCP 与技能页签升级为「已安装 / 精选 / 市场」三签布局，支持在线市场浏览、搜索、分类筛选与一键安装，插件卡片接入真实图标与作者头像兜底。
- 启动项编辑框支持一键将当前所选用户目录设为系统用户环境变量 `DSH_HOME`（#119）。

### 体验优化

- 启动项编辑与实例配置分离：首页启动项卡片恢复独立编辑按钮与双列编辑弹窗，已安装插件的更新按钮并入版本号旁，界面动画全面支持系统的「减少动态效果」。
- 实例配置弹窗打开期间展示居中加载动画，避免数据就绪前出现空白弹窗；移除首页启动项鼠标悬浮时的整行灰底。

### 问题修复

- 禁止将 `dsh` 用户目录与版本数据目录设在 DSH-X 安装目录内，防止卸载或升级启动器时误删用户数据（#119）。
- 放宽插件市场全量索引拉取超时并增加并发请求去重，避免代理环境下大索引流式读取被中途掐断或静默预取失败后无法自动重试。

### 其他变更

- 移除独立的 npm CLI 包装包（`@yyh001/dsh-x`），只保留跨平台核心包 `dsh-x-core`。
- 外壳与核心版本都升到 `0.1.27-rc.5`，rc 通道会收到新的安装包与核心更新。

Full Changelog: [v0.1.27-rc.4...v0.1.27-rc.5](https://github.com/yyh-001/DSH-X/compare/v0.1.27-rc.4...v0.1.27-rc.5)

## English

### New Features

- Add Computer Use (`dsh-x-computer-use`): the shell holds desktop permissions, enabled by default with per-app first-use authorization, a global `Ctrl+Alt+Backspace` emergency stop shortcut, and an action audit log (#113).
- Upgrade the Plugins, MCP, and Skills tabs in instance details to a three-tab layout (Installed / Curated / Market) with live market browsing, search, category filters, one-click install, and real plugin icons with author avatar fallbacks.
- Add a toggle in the launch item editor to set the selected user directory as the user `DSH_HOME` environment variable (#119).

### Improvements

- Separate launch item editing from instance configuration with a dedicated edit button and two-column dialog on home cards, move the plugin update badge next to the version number, and respect reduced-motion preferences across UI animations.
- Show a centered loading spinner while opening the instance configuration dialog to avoid a blank flash, and remove the full-row gray hover background on home launch items.

### Bug Fixes

- Disallow setting the `dsh` user directory or version data directory inside the DSH-X installation directory to prevent data loss during launcher upgrades or uninstallation (#119).
- Increase the timeout for fetching the full plugin market index, deduplicate concurrent requests, and retry automatically when opening the market tab after a failed background prefetch.

### Chores

- Remove the standalone npm CLI wrapper package (`@yyh001/dsh-x`) and keep only the cross-platform core package `dsh-x-core`.
- Bump both shell and core versions to `0.1.27-rc.5` so the rc channel receives the new installers and core update.
