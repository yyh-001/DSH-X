本预发布版本修复设置页打开「悬浮窗」后没有任何悬浮球的问题，并加固悬浮球的启停。

### 问题修复

- **修复悬浮球打不开**：悬浮窗服务此前没有声明进 `AndroidManifest.xml`，系统拒绝启动且没有任何提示；现在已补上服务声明，打开开关即可看到悬浮球。
- **启动失败会回滚**：悬浮球起不来时不再假装已开启，开关会退回关闭状态并提示检查系统权限。

### 体验优化

- **悬浮球自动恢复**：App 被系统回收后重新打开，只要开关仍开着且权限还在，悬浮球会自动重新出现。

### 其他变更

- 核心包 `dsh-x-core` 升至 `0.2.1-rc.6`（桌面 Electron 外壳保持 `0.2.0`），重新打包并签名的 Android APK 随本版本发布。

Full Changelog: [v0.2.1-rc.5...v0.2.1-rc.6](https://github.com/yyh-001/DSH-X/compare/v0.2.1-rc.5...v0.2.1-rc.6)

## English

This pre-release fixes the floating window showing nothing after enabling it, and hardens its start/stop.

### Bug Fixes

- **Fix the floating ball not appearing**: the floating-window service was missing from `AndroidManifest.xml`, so the system refused to start it without any message. The service is now declared, and the ball appears as soon as the switch is turned on.
- **Rollback when starting fails**: the app no longer pretends the floating window is on; the switch reverts and asks you to check the system permission.

### Improvements

- **Automatic restore**: If the app process is reclaimed, opening the app again restores the floating ball as long as the switch is on and the permission is still granted.

### Chores

- Bump `dsh-x-core` to `0.2.1-rc.6` (the Electron desktop shell stays at `0.2.0`); ship a rebuilt, signed Android APK with this release.
