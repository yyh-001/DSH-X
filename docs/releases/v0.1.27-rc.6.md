### 新增功能

- DSH-X 精选插件清单接入多镜像自动回退（`gh-proxy` / `ghfast` / `jsDelivr`），按设置页「下载源」排序并在直连 GitHub 不可达时自动切换。

### 体验优化

- 启动项编辑弹窗的「用户目录」与「用哪个实例」统一改为应用内富下拉选择器并各自独占一行，支持直接跳转「创建项目」与「管理实例」。
- 「添加实例 → 自定义」的弹窗宽度、字段排布、实例展示文案与控件高度全面对齐「编辑启动项」。
- 优化启动项图标选择浮层的按钮尺寸、选中高亮、阴影层次与深色模式观感；精简技能页签，移除「OpenAI 精选」子签。

### 问题修复

- 修复 DSH-X 精选插件清单分支指向错误导致拉取 404 的问题，改为读取默认 `Staging` 分支。
- 修复实例详情中 MCP 与技能双列卡片行高压缩重叠的问题。
- 修复「编辑启动项」中图标选择器按钮样式未生效、操作按钮尺寸与描边错位的问题。

### 其他变更

- 仅核心版本升至 `0.1.27-rc.6`（外壳版本保持 `0.1.27-rc.5`），`rc` 通道直接通过 `dsh-x-core` 在线更新，不出新安装包。
- 精简中英文 README 内容与顶部排版。

Full Changelog: [v0.1.27-rc.5...v0.1.27-rc.6](https://github.com/yyh-001/DSH-X/compare/v0.1.27-rc.5...v0.1.27-rc.6)

## English

### New Features

- Add automatic multi-mirror fallback (`gh-proxy`, `ghfast`, `jsDelivr`) when fetching the DSH-X curated plugin manifest, following the configured download source and falling back automatically if GitHub is unreachable.

### Improvements

- Upgrade the User Directory and Instance dropdowns in the Edit Launch dialog to full-width in-app rich pickers with direct shortcuts to Create Project and Manage Instances.
- Align the Add Instance (Custom) dialog width, field layout, instance labels, and control heights with the Edit Launch dialog.
- Polish the launch icon picker popover sizing, active highlight, elevation, and dark-mode buttons; simplify the Skills tab by removing the "OpenAI Curated" subtab.

### Bug Fixes

- Fix 404 errors when loading the DSH-X curated plugin manifest by pointing to the default `Staging` branch.
- Fix overlapping rows in the two-column MCP and Skills card grids inside instance details.
- Fix missing icon picker button styles and mismatched upload/reset button sizes in the Edit Launch dialog.

### Chores

- Bump core version only to `0.1.27-rc.6` (shell stays at `0.1.27-rc.5`); the `rc` channel receives the update via the `dsh-x-core` npm package without rebuilding installers.
- Refine Chinese and English README content and header layout.
