本预发布版本汇总了自 `v0.2.1-rc.3` 以来对 Android 通知、后台常驻与 WebView 悬浮界面的更新。

### 新增功能

- **系统通知默认开启**：进入手机控制台后自动申请通知权限并启动后台同步，不用再手动去设置里打开；设置项显示真实开启状态，手动关闭后不再自动打开。
- **后台运行授权**：设置页新增「后台运行」，未允许时可一键拉起系统「允许后台运行（忽略电池优化）」弹窗，首次开启通知时也会自动申请，减少锁屏后通知被系统清理。

### 体验优化

- **WebView 顶部栏改为悬浮胶囊**：去掉原生顶部导航条，页面全屏显示；右上角浮动一枚可拖动的实例胶囊（状态点 + 实例名 + 运行中数量），点按弹出实例切换抽屉，长按重载页面，拖动后的位置会记住。
- **悬浮窗可关闭**：设置页新增「悬浮窗」开关（默认开启），关闭后下次进入实例不再显示胶囊，改用系统返回手势。
- **常驻通知更安静**：后台通知改为静默、不进锁屏、不占角标且可一键划掉，App 在前台时不再显示这条通知，只有退到后台才出现。

### 问题修复

- 修复常驻通知无法划掉、在 App 前台时仍长时间挂在通知栏的问题。

### 其他变更

- 核心包 `dsh-x-core` 升至 `0.2.1-rc.4`（桌面 Electron 外壳保持 `0.2.0`），重新打包并签名的 Android APK 随本版本发布。

Full Changelog: [v0.2.1-rc.3...v0.2.1-rc.4](https://github.com/yyh-001/DSH-X/compare/v0.2.1-rc.3...v0.2.1-rc.4)

## English

This pre-release summarizes the changes since `v0.2.1-rc.3` to Android notifications, background running, and the floating WebView UI.

### New Features

- **Native notifications on by default**: Entering the mobile console now requests notification permission and starts background sync automatically, so there is no need to enable it by hand. Settings reflects the real state, and an explicit opt-out is remembered across launches.
- **Background running permission**: Settings gains a **Background running** row that opens the system battery-optimization exemption dialog when not yet allowed, and the app asks once when notifications are first enabled, so the OS is less likely to kill notification sync while the phone is locked.

### Improvements

- **WebView top bar replaced by a floating pill**: The native top navigation bar is gone and the page is full screen; a draggable instance pill (status dot, instance name, running count) floats in the top-right corner. Tap it to open the instance switcher, long-press to reload, and its dragged position is remembered.
- **Floating pill can be turned off**: A new **Floating pill** switch in Settings (on by default) hides the pill the next time you open an instance, leaving only the system back gesture.
- **Quieter background notification**: The ongoing notification is now silent, hidden on the lock screen, badge-free, and can be swiped away; it no longer shows while the app is in the foreground and only appears once the app goes to the background.

### Bug Fixes

- Fix the background notification being non-dismissible and lingering in the shade while the app was in the foreground.

### Chores

- Bump `dsh-x-core` to `0.2.1-rc.4` (the Electron desktop shell stays at `0.2.0`); ship a rebuilt, signed Android APK with this release.
