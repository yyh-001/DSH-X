`0.1.26-rc.2` 是纯核心更新：外壳仍是 `0.1.26-rc.1`，核心随 `rc` 通道发布。

### 新增功能

- 插件页支持**添加和卸载插件**：npm 包名、本地绝对路径、Git 地址都可以；装完自动把 bundle 挂进层栈，卸载时一并清掉依赖、层栈条目和补丁层里的开关残留。
- 首页插件弹窗的「更多操作」新增 **Profile 备份与回退**入口。
- 配置回退与「立即备份」增加进度条和加载动画，依赖重装时显示真实进度。

### 体验优化

- 配置回退后自动按还原的清单重装依赖，不再出现整排「包不可用」。
- 「修复环境」（安全启动）后，插件列表如实显示为关闭；打开开关会重新挂回 bundle 清单。
- 插件弹窗固定高度，右上「更多操作」菜单不再被卡片底边裁掉。

### 问题修复

- 慢机器上 dsh 启动被 instance-link 的 5 秒握手超时自杀（零输出 `exit 1`）；现在连接已建立就不算失去监管，失败时也会把原因写进启动器日志。
- 安全启动的补丁层备份在管理器重启后无法识别、首页没有还原入口；现在从备份侧车恢复入口，并在安全启动前额外存一份配置快照。
- `runtimeNode()` 不再优先使用旧安装残留的 `node.exe`（低于 dsh 要求的 Node 版本）；启动日志会写明实际运行时及版本。
- 备份列表的「回退到此备份」不再被渲染成禁用。

### 其他变更

- 本次只更新核心；外壳和安装包版本保持 `0.1.26-rc.1`。

## English

`0.1.26-rc.2` is a core-only update: the shell stays at `0.1.26-rc.1`, and the core ships on the `rc` channel.

### New Features

- Add and remove plugins from the plugins page: npm names, local absolute paths, and Git URLs. Installed bundles are mounted into the layer stack automatically; removal also cleans dependencies, the bundle entry, and leftover patch-layer switches.
- The home plugin dialog's "More actions" menu now has **Profile backups & rollback**.
- Progress bar and loading state for rollback and "Back up now", with real progress while dependencies are reinstalled.

### Improvements

- Rolling back a profile now reinstalls dependencies from the restored manifest, so plugins no longer stay "package unavailable".
- After "Repair environment" (safe start), the plugin list now shows removed bundles as off; turning one back on remounts it.
- The plugin dialog has a fixed height, so the "More actions" menu is no longer clipped by the card's bottom edge.

### Bug Fixes

- On slow machines dsh could kill itself on the 5-second instance-link handshake timeout (zero output, `exit 1`). An established connection no longer counts as lost supervision, and failures now write a reason to the launcher log.
- Safe-start patch-layer backups were invisible after a manager restart and had no restore entry on the home page. The entry is now derived from the backup sidecar, and an extra config snapshot is taken before safe start.
- `runtimeNode()` no longer prefers a stale bundled `node.exe` below dsh's required Node version; the startup log states the actual runtime and version.
- "Restore this backup" buttons in the backup list are no longer rendered disabled.

### Chores

- Core-only release; the shell and installer stay at `0.1.26-rc.1`.
