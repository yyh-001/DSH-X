本次只发核心：`dsh-x-core@0.1.26-rc.4`。外壳保持 `0.1.26-rc.3`，不需要重装；rc 外壳会在启动器里收到这次核心更新。

### 启动项日志

- 日志弹窗改成页签：原始日志 / 耗时构成 / 空间构成 / 插件诊断，只有采到数据的页签才出现。
- 耗时构成把原生/GC 按调用方归到包，并单列 `lstat` / `readFileUtf8` / `open` 等系统调用与 GC 明细。
- 插件耗时改成「加载 + 运行」：启动期模块解析、读取沿 import 依赖图归到插件，共用依赖按引用它的插件均摊，能直接看到每个插件带依赖的真实耗时。
- 空间构成把传递依赖归到插件，拆成插件本体 / 插件依赖 / 运行时 / 运行时依赖 / 配置与数据；标题和合计固定，内容在卡片内部滚动。

### 版本管理

- 每个已安装版本显示磁盘占用，弹窗顶部显示总占用。

### 问题修复

- #90：旧 DSH_HOME 删除或换盘后，`settings.json` 里 `environmentPorts` 留下的端口钉子会被清掉；移除用户目录、删除启动项时也会释放对应端口，不再永久占住端口号。

### 其他变更

- 外壳版本保持 `0.1.26-rc.3`，核心版本 `0.1.26-rc.4`；只改核心层，不重新出安装包。
- macOS 最低版本仍是 13（Electron 44 / Chromium 152 的要求）。

## English

This is a core-only release: `dsh-x-core@0.1.26-rc.4`. The shell stays at `0.1.26-rc.3`, so no reinstall is needed; rc shells will receive this core update from the launcher.

### Launch log

- The log dialog is now tabbed: raw log / time breakdown / storage breakdown / plugin diagnosis, with only tabs that have data shown.
- The time breakdown attributes native/GC samples to the calling package and lists syscall/GC types such as `lstat`, `readFileUtf8` and `open` separately.
- Plugin time is now "load + run": module resolution and file reads during startup are attributed to plugins along the import graph, with shared dependencies split across the plugins that use them, so each plugin's true cost including its dependencies is visible.
- The storage breakdown rolls transitive dependencies up to plugins and splits the total into plugin code / plugin dependencies / runtime / runtime dependencies / config & data; the header stays fixed while the card scrolls internally.

### Version manager

- Each installed version shows its disk usage, with the total at the top of the dialog.

### Bug Fixes

- #90: port pins left in `settings.json` under `environmentPorts` are cleaned up after an old DSH_HOME is deleted or moves to another drive; removing a user directory or deleting a launch preset also releases the corresponding port instead of reserving it forever.

### Chores

- Shell version stays `0.1.26-rc.3`; core version is `0.1.26-rc.4`. Core-only change, no new installer.
- macOS minimum remains 13 (required by Electron 44 / Chromium 152).
