# DSH-X 大肥鱼桌面终端设计与实施

**Goal:** 将独立壁纸升级为有完整终端排版和 DSH-X 短开场的桌面，保留大肥鱼、DeepSeek 蓝色、时钟、频谱、自动深浅色与 60 FPS 上限。

**Architecture:** 原生 DOM/CSS/SVG；复用原角色和水面。`terminal.css` 替代之前的简单布局，`intro.js` 单独处理开场、跳过、重播及减弱动画，主题、时钟和频谱逻辑继续复用。

**Tech Stack:** 原生 HTML/CSS/JavaScript、几何 SVG、既有 WebGL 水面，无新增依赖或网络资源。

参考：https://github.com/LBEILC/RhineLabWallpaper 和 https://rhine.lubeiluchen.cc/ 的开场节奏、字号层次与终端分区；不使用该项目的 Logo、配色和代码。

- 蓝白与蓝黑配色，品牌开场仅保留 DSH-X 字标；按用户反馈去掉左上角重复的小头像与 DSH-X 标识，只留 DEEPSEEK HARNESS 页眉。
- 左侧品牌大字号与互动角色，右侧本机时间、日期、星期、时区和频谱；底部重播按钮可用。
- 开场约 2.7 秒，DSH-X 字标与下方进度条从左向右同步展开；不引入假的权限或登录操作。
- 800 px 以下采用紧凑布局，短屏控制字号；装饰层不拦截角色与水面点击。
- 角色向右移动 3vh、上移 5vh；桌面依次展开标题、时间、频谱与页脚，圆环缓慢转动、状态灯呼吸、时钟冒号闪动，隐藏或宿主暂停时停止，关闭动画或系统减弱动画时静态显示。
- 移除大标题下的“桌面陪伴终端 + INTERACTIVE / 大肥鱼”说明；按用户澄清，底部标识保留透明背景，文字和条码使用固定黑色，不增加底框。
- 开场遮罩完全退场后再启动约 1.9 秒的桌面入场：角色从屏幕下方浮出，圆环显现，标题、时间、日期、频谱、角色标注和页脚依次加载；频谱区域从左展开，不伪造音频柱数据。
- 右上角模式按钮一键切换昼夜，背景、文字、水面与角色配色约 700ms 过渡；手动覆盖当前时段，下一次自动分界恢复时间模式，WE 主题选项改变时取消覆盖；不重播入场，不影响透明黑字底部标识。
- 白天水面保持普通混合以支持平滑过渡，透明度提高至 58%，增强浅色焦散亮纹；深色维持 16%，保证昼夜都有水纹且终端文字清晰。
- 验证时间、频谱、开场重播/跳过/关闭、減弱动画、宽窄屏排版；备份并更新现有 WE 项目及 ZIP。
- 不提交、不发版，不修改启动器管理界面。
