FAQ常见问题

有了官方桌面端，为什么还要启动器？

官方桌面端是一份打包好的 DSH，稳定、开箱即用。DSH-X 管的是另一层：装哪个版本、同时跑几个环境、插件与整合包怎么管、启动坏了怎么退。界面不另做。

两个都装会冲突吗？

不会，可以同时装、各开各的窗口。DSH-X 只是把你本机安装的 DSH 版本启动起来，不替换官方桌面端。

什么时候其实不需要 DSH-X？

只用最新版、只开一个环境、不折腾插件的话，官方桌面端就够了。需要多版本并存、多环境并行、整合包市场、启动失败回滚或手机访问时，再用启动器。

打开的界面是官方原版吗？

是。DSH-X 不重做 DSH 的 Web 页面，启动后看到的就是官方原版界面；它负责的是启动之前和之外的事。DSH-X 是社区开源项目，不是 DeepSeek 官方产品。
