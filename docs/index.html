选择版本，启动官方原版 DSH Web。安装、更新与插件管理，都在一个地方完成。

下载 Windows 版 下载 macOS 版

真实桌面端界面预览

01 / VERSIONS

版本，一处管理

安装、启动、更新与切换版本，操作集中在一个界面。

02 / PLUGINS · MODPACKS

插件与整合包

查看已装插件、一键开关与更新；整合包把一批插件和配置一次装进独立 profile。

03 / ORIGINAL WEB

原版 Web 体验

在系统浏览器里使用官方原版 DSH Web 页面。
