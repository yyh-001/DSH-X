# dsh-x-computer-use

DSH-X 的电脑操作（Computer Use）插件：默认关闭、由 DSH-X 桌面外壳托管桌面驱动与全局急停开关，向模型提供经过授权与审计的桌面应用查看与操作能力。

## 特性

- **默认关闭**：只有用户主动在 DSH-X 管理器「设置 → 常规 → 电脑操作」中开启，且实例由 DSH-X 桌面外壳启动时才会注册工具；用户自己在终端启动 `dsh` 时静默降级，不向模型暴露任何工具。
- **权限归属外壳**：所有无障碍树读取、截图、鼠标/键盘输入都在 Electron 外壳进程内执行，不把原生驱动挂进 `dsh` 子进程。
- **应用级授权**：复用 `@deepseek-ai/dsh-cua` 的授权卡片与存储（按应用身份持久化授权/拒绝，拒绝或撤销后旧句柄立即失效）。
- **随时可停**：支持全局快捷键（`Control+Alt+Backspace` / macOS `Command+Option+Backspace`）、系统托盘菜单与管理页按钮 1 秒内中断在途操作并拒收后续调用。
- **审计脱敏**：审计日志仅记录时间、应用、动作类型与结果，绝不记录输入的正文内容。
